### 1. Bloomberg Terminal — Oil Price, Sentiment & Airline Stock Analysis
**Tools:** Python · SQL · Bloomberg Terminal · Regression Modelling · Event Study Methodology  
**Dataset:** ~1,750 daily observations across 8 global airlines

**What I did:**
- Extracted and validated financial market data (equity returns, Brent crude prices, investor sentiment) via Bloomberg Terminal

### 2. Hotel Review Sentiment NLP Classifier — 500,000+ Records
**Tools:** Python · Scikit-learn · NLTK · SpaCy · NLP · Text Classification  
**Dataset:** 500,000+ hotel reviews

**What I did:**
- Built an end-to-end NLP sentiment classification pipeline from raw text to production-ready model
- Engineered features via tokenisation, stopword removal and lemmatisation (SpaCy)
- Iterated across 3 model architectures, achieving **88% classification accuracy**

**Key business insight:**
- **OTA-channel guests (Booking.com, Expedia) gave systematically worse value sentiment than direct-booking guests at identical room rates**
- Root cause: expectation-setting at booking stage, not pricing — directly actionable for revenue and channel strategy teams

📂 [View project notebook](./hotel-nlp-sentiment.ipynb/)
